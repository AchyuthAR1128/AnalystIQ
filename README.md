# AnalystIQ — AI-Powered Data Analytics Copilot

AnalystIQ is an AI-powered data analytics copilot that helps transform messy business data into meaningful insights.

It simulates the workflow of a real-world data analyst by combining automated data cleaning, data-quality analysis, KPI generation, exploratory data analysis, interactive visualization, customer segmentation, and natural-language AI analysis.

## 🚀 Features

- 📂 Upload CSV or Excel datasets
- 🧹 Automatic data cleaning and preprocessing
- 🔍 Automated data-quality analysis
- 📊 KPI generation
- 📈 Automatic Exploratory Data Analysis (EDA)
- 📉 Interactive Plotly visualizations
- 🤖 Natural-language data analysis using Google Gemini
- 💻 AI-generated Pandas analysis code
- 🔐 Constrained code execution for AI-generated analysis
- 💡 Business-focused insights from analytical results
- 👥 K-Means customer/data segmentation
- 📄 Automated PDF analytics report
